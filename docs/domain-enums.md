# 도메인 코드 목록

AI 서버·FE·BE가 공통으로 쓰는 코드 값이다. 2026-11-05부터 FE·BE는 AI 서버의 정의를 따른다.

이 파일은 `uv run python scripts/generate_domain_doc.py`로 코드에서 생성한다. 값을 바꾸려면
`app/schemas/role_codes.py`, `app/schemas/activity.py`, `app/schemas/contest.py`를 고친 뒤
다시 생성한다.

- API로 주고받는 값은 코드 열이다. 한글 라벨은 화면 표시용이다.
- 역할은 공모전 도메인 23개 아래에 도메인별로 나뉘어 있다(역할 132개). 예를 들어 IT에는 백엔드·프론트엔드 개발이, 요리에는 한식·양식·중식·메뉴 기획이 있다.
- 팀은 다른 도메인의 역할도 모집할 수 있다(예: 요리 공모전 팀이 `VIDEO_EDITING`을 모집).
  도메인은 역할을 고르는 화면을 나누는 기준이지 제한이 아니다. 도메인 값은 API 요청·응답에 나오지 않는다.
- 처음부터 있던 역할 코드 10개(`BE`, `FE`, `Design`, `PM`, `Data`, `MARKETING`, `CONTENT`, `BUSINESS`, `RESEARCH`, `ETC`)는 값이 그대로다.
  각자 맞는 도메인에 들어갔고, 일부는 겹치는 의미를 새 코드로 떼어내 범위가 좁아졌다(예: AI는
  `Data`에서 `IT_AI`로). 그 전에 저장된 값은 팀 임베딩 재계산(`/internal/teams/embedding:refresh`)과
  의도 재추출(`/intents/extract`)로 다시 정규화해야 정확하다.

## 역할 구성 근거

도메인마다 실제 공모전 팀이 어떤 역할로 나뉘는지 확인한 자료다.

- **IT·소프트웨어**: 해커톤·IT 공모전 팀원 모집 글(기획·디자인·프론트엔드·백엔드·AI·데이터 수집/가공·데이터 시각화)과 IT 연합동아리 파트(UMC·YAPP: Web·Server·iOS·Android·Plan·Design)로 확인. 인프라/DevOps를 따로 모집한 사례는 없음.
- **게임·XR**: 게임 공모전 신청서 세부 분야(프로그래밍/그래픽/기획/운영QA), 스마일게이트 멤버십(프로그래머/그래픽 디자이너/기획자), XR 서비스 경진대회 팀의 Unity 개발자 모집, e스포츠 대학리그(LoL 5인·PUBG 4인)로 확인.
- **기획·아이디어**: 아이디어 공모전 팀은 기획(제안서 작성)·자료조사·발표로 나뉨(링커리어 팀원 모집 글). PPT 디자인 담당은 디자인 도메인으로 옮김.
- **광고·마케팅·네이밍**: 광고 공모전 팀(기획·카피·디자인·영상), PR 기획서 공모전, 퍼포먼스 마케팅 공모전, SNS 홍보 서포터즈(BE 데이터 경영/컨설팅/마케팅 154건 중 약 100건)로 확인.
- **디자인·캐릭터·웹툰**: 광고 공모전 디자이너(포스터·스토리보드)·기자단 카드뉴스 담당·PPT 디자인 담당 모집, 웹툰 공모전의 작화 부문, 애니메이션·모션그래픽 공모전으로 확인.
- **사진·영상**: 다큐·단편영화·영상 콘텐츠 팀의 연출·촬영·편집·대본 분담, 대학 방송국 구성, 생성형 AI 영상 공모전(BE 데이터 10건 안팎)으로 확인.
- **언론·미디어·콘텐츠**: 기자단(취재·동영상·카드뉴스·블로그 기자), 학생 리포터(에디터 팀·크리에이터 팀), 대학 방송국(PD·작가·아나운서), 라디오 콘텐츠 공모전으로 확인.
- **문학·글쓰기**: 웹툰 글·그림 분리 모집(다음웹툰·대원씨아이), 대한민국 스토리 공모대전(개인·팀), 시나리오 공모전 팀 응모, 그림책 공동 창작, 출판 프로젝트의 편집·교정 담당으로 확인.
- **논문·학술**: 통계청 논문 공모전(개인 또는 3명 이하 팀)과 위비티 논문 공모전 가이드의 역할 분담(데이터 수집·선행연구·통계 모델링·교정), 계량·통계 분석 팀원 모집 글로 확인.
